# Android App (sub-project 5) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** One Android app for phones and TVs (Google Play, app id `de.jbpcapital.portfolioviewer`) that opens a Portfolio Viewer server — the hosted one or a self-hosted one — with the comfort of a native app: phones open the dashboard, TVs open TV mode and pair with a code; offline screen with automatic retry, file picker for CSV import, CSV export downloads, links to other sites in the browser, the screen kept on in TV mode.

**Architecture:** `apps/android` is a small Gradle project (AGP 9.4, built-in Kotlin, Gradle 9.7.1 wrapper, JDK 21), no dependencies beyond the Android SDK. All content stays in the web app, so a web deployment updates the app. Pure logic (server address rules, which links stay in the app) lives in plain Kotlin objects with JVM unit tests. A native first-run screen asks for the server and checks it through `/api/health` (which names the app), so the app never opens an arbitrary site as if it were the portfolio server.

**Tech Stack:** Kotlin, Android SDK 36 (min 24), `android.webkit.WebView`, JUnit 4 for unit tests. Toolchain on this machine: `%LOCALAPPDATA%\Android` (JDK 21, SDK 36, TV emulator image API 34).

**Spec:** `docs/superpowers/specs/2026-09-26-portfolio-viewer-design.md` §8 (Android): one app for phone and TV (launcher + leanback), Kotlin WebView, server selection (default portfolio.jbpcapital.de), phone loads `/`, TV loads `/tv`, offline screen with retry, keep screen on in TV mode, D-pad and Back passed to the page, file picker for CSV import, external links in the browser; Play Store internal track first; store listing EN/DE, phone and TV screenshots, privacy policy on jbpcapital.de.

## Design decisions

- **Server choice:** first start shows a native screen with the address field prefilled with `https://portfolio.jbpcapital.de`; "Connect" normalizes the input (adds `https://` when no scheme is given, drops paths and trailing slashes) and accepts it only when `GET /api/health` answers JSON with `"app":"portfolio-viewer"`. The address is stored in `SharedPreferences`. It can be changed from the offline screen and from a launcher shortcut ("Change server").
- **Cleartext HTTP** is allowed because self-hosters run servers on their home network (`http://192.168.x.x:3310`); the user types that address on purpose.
- **In-app vs. browser:** same origin as the server stays in the WebView; everything else (e.g. a link to jbpcapital.de) opens in the browser.
- **TV detection:** `UiModeManager.currentModeType == UI_MODE_TYPE_TELEVISION` or the leanback feature → start path `/tv`, screen kept on, immersive full screen. Phones start at `/`.
- **Back:** WebView history first (phone); on the TV the page has no history, so Back leaves the app.
- **Downloads:** CSV export through `DownloadManager` with the WebView's cookies for the server (the export needs the session).
- **Signing:** release builds are signed only when the upload key properties (`pvUploadStoreFile`, `pvUploadStorePassword`, `pvUploadKeyAlias`, `pvUploadKeyPassword`) are set in `~/.gradle/gradle.properties`; the key itself is kept outside the repository, on the maintainer's machine.
- **Translations:** English in `values/`, German in `values-de/` (the Android counterpart of `de.json`, covered by the approved "English UI with German translation").

## Global Constraints

- English everywhere in the repository except `values-de/strings.xml`.
- No secrets in the repository: no keystore, no passwords, no server credentials.
- The app must work against the local demo stack from the emulator (`http://10.0.2.2:3310`).

## Review Focus

- The first-run check must refuse a server that is not Portfolio Viewer (a phishing page must not be opened as the app).
- Links to other origins must leave the WebView; `file:`, `content:` and `javascript:` navigations must not open inside it.
- The session cookie must survive app restarts (CookieManager flush on pause).
